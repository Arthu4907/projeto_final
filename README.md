# 📝 Lista de Tarefas

Um projeto simples de gerenciamento de tarefas desenvolvido utilizando **HTML, CSS e JavaScript**. O objetivo é praticar conceitos fundamentais de desenvolvimento web, manipulação do DOM e armazenamento de dados no navegador.

## 🚀 Funcionalidades

- **Adicionar tarefas:** permite cadastrar novas tarefas.
- **Concluir tarefas:** permite marcar tarefas como concluídas ou pendentes.
- **Editar tarefas:** permite modificar o conteúdo de uma tarefa.
- **Excluir tarefas:** permite remover tarefas individualmente.
- **Filtrar tarefas:** visualizar todas, pendentes ou concluídas.
- **Contador:** exibe a quantidade total de tarefas e tarefas concluídas.
- **Limpar tarefas:** permite excluir todas as tarefas.
- **Armazenamento local:** mantém as tarefas salvas mesmo após atualizar ou fechar o navegador.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da aplicação.
- **CSS3:** estilização e responsividade da interface.
- **JavaScript:** desenvolvimento da lógica e interatividade.
- **LocalStorage:** armazenamento de dados diretamente no navegador.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Comece a adicionar e organizar suas tarefas.

## 📚 Conceitos praticados

Durante o desenvolvimento, foram aplicados os seguintes conceitos:

- Variáveis (`let` e `const`).
- Funções.
- Condicionais.
- Arrays e objetos.
- Métodos `push()`, `filter()`, `map()` e `find()`.
- Manipulação do DOM.
- Eventos com `addEventListener()`.
- Criação dinâmica de elementos HTML.
- Armazenamento com LocalStorage.
